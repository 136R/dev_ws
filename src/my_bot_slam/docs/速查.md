# my_bot_slam 速查

## 编译

```bash
cd ~/dev_ws
colcon build --packages-select my_bot_slam --symlink-install
source install/setup.bash
```

## 启动

```bash
# 仿真
ros2 launch my_bot_slam slam.launch.py use_sim_time:=true mode:=mapping
ros2 launch my_bot_slam slam.launch.py use_sim_time:=true mode:=localization   # 默认

# 实机（先起底盘：ros2 launch my_bot_hw robot_bringup.launch.py）
ros2 launch my_bot_slam slam.launch.py mode:=mapping
ros2 launch my_bot_slam slam.launch.py mode:=localization

# slam + nav 一起
ros2 launch my_bot_slam nav_slam.launch.py use_sim_time:=true slam_mode:=localization
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `mode` | `localization` | `mapping` = `async_slam_toolbox_node`；`localization` = `localization_slam_toolbox_node` |
| `use_sim_time` | `false` | 决定用 `mapper_params_sim.yaml` 还是 `mapper_params_hw.yaml` |
| `map` | 空 | 地图名（仅 localization）；留空则读 `~/.maps/current_map` |

localization 启动时会打印它认了哪张图：

```
[slam] 地图 "my_map" → 定位位姿图 /home/bingda/.maps/my_map/my_map.posegraph
```

## 建图 → 存图

```bash
# 1. 建图模式
ros2 launch my_bot_slam slam.launch.py use_sim_time:=true mode:=mapping

# 2. 遥控把场地跑一遍
ros2 run teleop_twist_keyboard teleop_twist_keyboard \
  --ros-args -r cmd_vel:=/cmd_vel_keyboard

# 3. 存图（app 后端要在跑；名字不能叫 map）
~/dev_ws/src/my_bot_slam/scripts/save_map.sh <地图名>
```

`save_map.sh` 一次凑齐「一张完整地图」的四样东西到 `~/.maps/<地图名>/`：
posegraph（定位）、pgm+yaml（app 显示 + keepout 掩码）、topology、tiles，
并设为 `current_map`。之后 `slam.launch.py` / `nav.launch.py` 不带 `map:=` 就会自动用它。

> ⚠️ **必须在 `mode:=mapping` 下执行。** localization 模式会拒绝 `serialize_map`，
> 但**照样返回 `result=0`** —— 脚本靠文件新鲜度判断成败，你自己手工调服务时别只看返回码。

只要位姿图（比如实机上还没接 app）：

```bash
ros2 service call /slam_toolbox/serialize_map slam_toolbox/srv/SerializePoseGraph \
  "{filename: '$HOME/.maps/<地图名>/<地图名>'}"
```

> `filename` **不带扩展名**，会生成 `.posegraph` + `.data` 两个文件。

## 换地图

```bash
curl -fsS "localhost:8080/setCurrentMap?name=<地图名>"   # 或在 app 上点
# 重启 slam.launch.py 和 nav.launch.py（不带 map:= 时自动跟随）

# 也可临时指定，不改 current_map
ros2 launch my_bot_slam slam.launch.py use_sim_time:=true mode:=localization map:=<地图名>
```

## 调试

```bash
ros2 topic hz /map
ros2 topic echo /map --field info --once          # 尺寸 / 分辨率 / origin
ros2 run tf2_ros tf2_echo map odom                # 定位是否在发 map→odom
ros2 topic hz /scan_filtered                      # slam 吃的是过滤后的 scan
```

## 排错

| 现象 | 排查 |
| --- | --- |
| 起 localization 报找不到 `.posegraph` | 这张图是 app「另存为」出来的且认亲失败 → 全新场地，用 `mode:=mapping` + `save_map.sh` |
| `save_map.sh` 报"位姿图没写出来" | 你在 localization 模式下跑的，切到 `mode:=mapping` |
| `/map` 每次启动尺寸不一样 | 正常。localization 模式下 `/map` 随扫描累积变化，不影响 keepout（掩码自带 origin） |
| 定位漂移 | 见 [建图调参.md](建图调参.md)；先查里程计和雷达外参 |
