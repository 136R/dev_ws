# 多地图与禁行区（Keepout）

> app（上位机 GUI）那一侧 —— 后端接口、`~/.maps` 契约、**不变量清单**、前端补丁 ——
> 全在 [docs/APP/](../../../docs/APP/)。动 `~/.maps` 之前先读它的 README。
>
> 本文只讲 ROS 侧：launch 怎么解析地图、掩码怎么进 costmap。
> 这套机制**不依赖 app** —— 换 RViz 手工画掩码也照样成立。

## 一个文件夹 = 一张完整地图

```
~/.maps/
├── current_map        # 唯一的地图名真相：app 选图时写入；launch 启动时读，运行中也有节点盯着它
├── map/               # app 从 /map 持续镜像的实时快照。【保留名】正式地图别叫这个
└── <name>/
    ├── <name>.posegraph / .data   # slam_toolbox 定位
    ├── <name>.yaml / .pgm         # 栅格图（原图，画笔不改它）
    ├── <name>_keepout.yaml / .pgm # 禁行区掩码：只有画笔涂的格子是黑的
    ├── <name>.topology            # 导航点
    └── tiles/                     # app 前端瓦片
```

`slam.launch.py` 与 `nav.launch.py` 都不带 `map:=` 时会自动读 `~/.maps/current_map`。
**运行中在 app 上切图不用重启**：约 2s 内各部分跟着换 ——

| 谁 | 怎么跟 |
| --- | --- |
| 定位 | `slam_map_switcher` 调 `/slam_toolbox/deserialize_map`（定位模式只能用 `LOCALIZE_AT_POSE`），缺位姿图同样按源图补齐 |
| 禁行区 | `keepout_mask_reloader` 改盯新图的 `_keepout` 文件并立刻加载（没有就生成空的） |
| 任务层 | 取消当前任务、清空队列、**不归位**，停在 STOPPED，任务卡显示原因；下一次召唤恢复接单 |

**切完必须在 app 上重定位一次**：slam_toolbox 没有全局重定位，车被暂定在新图原点。
重定位之前，按错位姿叠进 `/map` 的几帧激光会让地图多出"幻影墙"，`/initialpose` 一到就清掉（车不动也清）。
用 `map:=` 指定了地图启动的，不跟随 app 切图。

> **地图名不能叫 `map`。** app 后端把 `default_map_name` 硬编码为 `"map"`，会把订阅到的
> 地图话题持续镜像进 `~/.maps/map/`。正式地图只要不重名，画笔就绝不会被覆盖。

## 两种"新建地图"的方式

| 方式 | 产出 | 用在什么时候 |
| --- | --- | --- |
| **`save_map.sh <名字>`**（**必须** mapping 模式） | posegraph + pgm + tiles + topology，**完整一张图** | 建了一张**新场地**的图 |
| **app 的「另存为」** | 只有 pgm + tiles + topology，**没有 posegraph** | 从已有图**派生**（换个名字保存一份画笔方案） |

app 的「另存为」走后端的 `/saveMapEdit`，本质是"复制源图的栅格 + 套用画笔"，SLAM 几何完全不变，
所以它不产出位姿图。`slam.launch.py` 会**自动兜底**：发现某张图缺 posegraph 时，按
**几何完全一致 + 像素相似度 ≥90%** 在 `~/.maps/` 里找出它的源图，把位姿图复制过来补齐
（补一次，之后这张图就自足了），并在日志里说明认了谁：

```
[slam] 地图 "my_map7" 缺位姿图 —— 几何与 "my_map" 完全一致、像素相似度 99.7%，
       判定为它的派生图（app「另存为」）。复制其位姿图补齐
```

找不到源图（说明是全新场地）才报错，让你去用 `mode:=mapping` + `save_map.sh`。

## 禁行区原理（Nav2 标准 Costmap Filter）

app 后端把画笔单独存成 `~/.maps/<name>/<name>_keepout.pgm`：和原图同尺寸，**只有画笔涂过的格子是黑的**，
其余全白。由标准 `filter_mask_server` 加载后发布到 `/keepout_filter_mask`，`KeepoutFilter` 消费。
原图 `<name>.pgm` 不再被画笔改动；app 显示的瓦片是"原图 + 禁行区"叠出来的，看起来和以前一样。

| 掩码里的格子 | 结果 |
| --- | --- |
| 画笔涂的禁行区 (100) | → lethal ✔ |
| 空闲 (0) | **不会擦除** obstacle_layer 探到的动态障碍（KeepoutFilter 是 max 语义，0 永远不大于已有代价） |

- **橡皮擦只能擦禁行区，擦不掉原图的墙** —— 导航的墙来自 slam 的 `/map`，和这张掩码无关。
- 「另存为」会把源图的禁行区一起带到新图。
- 旧图（没有 `_keepout` 文件）启动时，`keepout.launch.py` 按原图尺寸生成一张全白的（= 没有禁行区）。
  以前画进原图里的禁行区不会迁移：app 上还显示黑色，但导航不认，要用就重画。

> 历史：
> - 早先有个 `keepout_mask_diff` 节点做"编辑图减干净图"，后来删了，改成"原图 + 画笔"整张当掩码。
> - 2026-10-22 起改成单独的 `_keepout` 文件：整张原图当掩码时墙也在里面，局部图加载会把墙叠胖、
>   NeuPAN 急停，所以 neupan_smac2d 局部图只能不加载；橡皮擦也是白擦。

### 节点

`nav.launch.py` 已内含（`keepout:=false` 可关）：

| 节点 | 作用 |
| --- | --- |
| `filter_mask_server` | 加载 `~/.maps/<name>/<name>_keepout.yaml` → 发布 `/keepout_filter_mask` |
| `costmap_filter_info_server` | 发布 `CostmapFilterInfo`，告诉 costmap 去哪订阅掩码 |
| `keepout_mask_reloader` | **监听 pgm 的 mtime，画笔一保存就调 `load_map` 热加载**（约 1s 生效，不重启任何节点）；app 切图时改盯新图 |
| `lifecycle_manager_keepout` | 管前两个 lifecycle 节点 |

`keepout_mask_reloader` 带 0.5s 去抖 —— 后端写 pgm 可能分多次落盘，等文件静默再加载，
避免读到写了一半的图。

### 要点

- `keepout_filter` 必须放在 costmap 的 `plugins` 里、**`inflation_layer` 之前** ——
  这样禁行区才会被膨胀（留出机器人间距）
- 六份配置的局部图都加载 `keepout_filter`，禁行区在局部也硬挡。
  ⚠️ NeuPAN 把局部图里每个致命格当一个障碍点，超过 `dune_max_num`（2500）会**均匀抽点**。
  1 m² 禁行区落到 2.5cm 局部图约 1600 点；仿真涂满走廊两侧到 7400 点仍不贴墙。
  **实机板子算力是瓶颈**：车要走的通道两侧 1.5m 内全涂满（约 9000 点）时控制循环频繁超时（18～19.7Hz）。
  别把通道两侧大片涂满，挡门口、挡一块区域这种正常用法点数只有几百到两千。
  数据见 `调参记录/2026-10-22-仿真NeuPAN-局部加回禁行区.md`
  （之前 10-21 去掉它是因为掩码含墙，方案 A 改成单独 `_keepout` 文件后这个原因已不存在）
- 掩码的尺寸/origin **不必**和 `/map` 一致 —— Nav2 按世界坐标对齐，各自带 origin 即可
  （实测掩码 109×106、costmap 79×79、origin 也不同，照样正确）

ros2 topic echo /costmap_filter_info --once
