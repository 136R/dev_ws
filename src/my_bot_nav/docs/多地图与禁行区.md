# 多地图与禁行区（Keepout）

> app（上位机 GUI）那一侧 —— 后端接口、`~/.maps` 契约、**不变量清单**、前端补丁 ——
> 全在 [docs/APP/](../../../docs/APP/)。动 `~/.maps` 之前先读它的 README。
>
> 本文只讲 ROS 侧：launch 怎么解析地图、掩码怎么进 costmap。
> 这套机制**不依赖 app** —— 换 RViz 手工画掩码也照样成立。

## 一个文件夹 = 一张完整地图

```
~/.maps/
├── current_map        # 唯一的地图名真相：app 选图时写入，launch 启动时读取
├── map/               # app 从 /map 持续镜像的实时快照。【保留名】正式地图别叫这个
└── <name>/
    ├── <name>.posegraph / .data   # slam_toolbox 定位
    ├── <name>.yaml / .pgm         # 栅格图（原图+画笔）= 同时就是 keepout 掩码
    ├── <name>.topology            # 导航点
    └── tiles/                     # app 前端瓦片
```

`slam.launch.py` 与 `nav.launch.py` 都不带 `map:=` 时会自动读 `~/.maps/current_map`。
**在 app 上选一张图、重启这两个 launch，定位 / 禁行区 / 显示就全都跟着切过去。**

> **地图名不能叫 `map`。** app 后端把 `default_map_name` 硬编码为 `"map"`，会把订阅到的
> 地图话题持续镜像进 `~/.maps/map/`。正式地图只要不重名，画笔就绝不会被覆盖。

## 两种"新建地图"的方式

| 方式 | 产出 | 用在什么时候 |
| --- | --- | --- |
| **`save_map.sh <名字>`**（**必须** mapping 模式） | posegraph + pgm + tiles + topology，**完整一张图** | 建了一张**新场地**的图 |
| **app 的「另存为」** | 只有 pgm + tiles + topology，**没有 posegraph** | 从已有图**派生**（换个名字保存一份画笔方案） |

app 的「另存为」走后端的 `/saveMapEdit`，本质是"复制源图的栅格 + 套用画笔"，SLAM 几何完全不变，
所以它不产出位姿图。`slam.launch.py` 会**自动兜底**：发现某张图缺 posegraph 时，按
**几何完全一致 + 像素相似度 ≥90%** 在 `~/.maps/` 里找出它的源图，把位姿图复制过来补齐
（补一次，之后这张图就自足了），并在日志里说明认了谁：

```
[slam] 地图 "my_map7" 缺位姿图 —— 几何与 "my_map" 完全一致、像素相似度 99.7%，
       判定为它的派生图（app「另存为」）。复制其位姿图补齐
```

找不到源图（说明是全新场地）才报错，让你去用 `mode:=mapping` + `save_map.sh`。

## 禁行区原理（Nav2 标准 Costmap Filter）

app 后端把"原图 + 画笔"存成 `~/.maps/<name>/<name>.pgm`。**这张图原样就是掩码** ——
由标准 `filter_mask_server` 加载后发布到 `/keepout_filter_mask`，`KeepoutFilter` 消费。
不需要任何自定义节点做差。

之所以能直接用，是因为 **KeepoutFilter 是 max 语义**（`data > old_data` 才覆盖）：

| 掩码里的格子 | 结果 |
| --- | --- |
| 原始墙体 (100) | → lethal。但 static_layer 本来就标了 lethal，**叠加无副作用** |
| 画笔涂的禁行区 (100) | → lethal ✔ 这就是我们要的 |
| 空闲 (0) | **不会擦除** obstacle_layer 探到的动态障碍（0 永远不大于已有代价） |
| 未知 (-1) | 直接 skip |

> 历史：早先有个 `keepout_mask_diff` 节点做"编辑图减干净图"，还为此把 app 的 `MapSubTopic`
> 改订 `/map_gui` 并加了转发。实测确认 max 语义后，**这些全部删除**，回到 Nav2 标准架构。

### 节点

`nav.launch.py` 已内含（`keepout:=false` 可关）：

| 节点 | 作用 |
| --- | --- |
| `filter_mask_server` | 加载 `~/.maps/<name>/<name>.yaml` → 发布 `/keepout_filter_mask` |
| `costmap_filter_info_server` | 发布 `CostmapFilterInfo`，告诉 costmap 去哪订阅掩码 |
| `keepout_mask_reloader` | **监听 pgm 的 mtime，画笔一保存就调 `load_map` 热加载**（约 1s 生效，不重启任何节点） |
| `lifecycle_manager_keepout` | 管前两个 lifecycle 节点 |

`keepout_mask_reloader` 带 0.5s 去抖 —— 后端写 pgm 可能分多次落盘，等文件静默再加载，
避免读到写了一半的图。

### 要点

- `keepout_filter` 必须放在 costmap 的 `plugins` 里、**`inflation_layer` 之前** ——
  这样禁行区才会被膨胀（留出机器人间距）
- 掩码的尺寸/origin **不必**和 `/map` 一致 —— Nav2 按世界坐标对齐，各自带 origin 即可
  （实测掩码 109×106、costmap 79×79、origin 也不同，照样正确）

### 检查

```bash
ros2 topic echo /keepout_filter_mask --once --field info
ros2 topic echo /costmap_filter_info --once
# 禁行区在 /global_costmap/costmap 里应为 lethal（RViz 看，或发目标看是否绕行）
```
