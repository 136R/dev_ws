# my_bot_nav 速查

## 编译

```bash
cd ~/dev_ws
colcon build --packages-select my_bot_nav --symlink-install
source install/setup.bash
```

## 启动 Nav2

```bash
# 仿真（默认 controller:=rpp）
ros2 launch my_bot_nav nav.launch.py use_sim_time:=true
ros2 launch my_bot_nav nav.launch.py use_sim_time:=true controller:=neupan

# 实机
ros2 launch my_bot_nav nav.launch.py
ros2 launch my_bot_nav nav.launch.py controller:=neupan
```

**已内含 keepout 禁行区流水线**，不需要再单独起 `keepout.launch.py`。

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `controller` | `rpp` | `rpp`（RegulatedPurePursuit）或 `neupan` |
| `use_sim_time` | `false` | 选 `config/sim/` 还是 `config/hw/` 下的参数 |
| `map` | 空 | 地图名；留空则读 `~/.maps/current_map` |
| `keepout` | `true` | `false` 关掉禁行区流水线 |
| `params_file` | 空 | 直接指定参数文件，绕过上面的四选一 |
| `autostart` | `true` | 自动拉起 Nav2 生命周期 |

## 完整仿真链路

```bash
ros2 launch my_bot launch_sim.launch.py
ros2 launch my_bot_slam slam.launch.py use_sim_time:=true mode:=localization
ros2 launch my_bot_nav  nav.launch.py  use_sim_time:=true controller:=neupan
cd ~/ros_flutter_gui && sh ./start.sh          # 浏览器 http://127.0.0.1:8080
```

## 发送导航目标

```bash
ros2 action send_goal /navigate_to_pose nav2_msgs/action/NavigateToPose \
  "{pose: {header: {frame_id: 'map'}, pose: {position: {x: 1.0, y: 0.5}, orientation: {w: 1.0}}}}"

# 只算路径不执行（验证全局规划）
ros2 action send_goal /compute_path_to_pose nav2_msgs/action/ComputePathToPose \
  "{goal: {header: {frame_id: 'map'}, pose: {position: {x: 1.5, y: -0.8}, orientation: {w: 1.0}}}}"

# 取消当前导航
ros2 action send_goal /navigate_to_pose --feedback ... # Ctrl-C，或：
ros2 topic pub --once /cmd_vel_keyboard geometry_msgs/msg/Twist "{}"   # 遥控优先级更高，可强行接管
```

## 禁行区

在 app 上画完点保存即可 —— `keepout_mask_reloader` 会在约 1s 内自动热加载，**不用重启**。

```bash
# 手动热加载（万一 reloader 没起）
ros2 service call /filter_mask_server/load_map nav2_msgs/srv/LoadMap \
  "{map_url: '$HOME/.maps/<地图名>/<地图名>.yaml'}"

# 检查
ros2 topic echo /keepout_filter_mask --once --field info
ros2 topic echo /costmap_filter_info --once
```

## 换地图

```bash
curl -fsS "localhost:8080/setCurrentMap?name=<地图名>"   # 或在 app 上点
# 然后重启 slam.launch.py 和 nav.launch.py（不带 map:= 时自动读 current_map）
```

## 调试

```bash
ros2 topic hz /plan /local_plan /cmd_vel_nav
ros2 topic echo /global_costmap/costmap --field info --once
ros2 lifecycle get /controller_server                    # 应为 active
ros2 param get /controller_server FollowPath.plugin      # 确认当前用的是哪个控制器

# NeuPAN 指标（发目标后立刻跑）
ros2 run my_bot_nav neupan_metrics.py --ros-args \
  -p goal_x:=1.5 -p goal_y:=1.5 -p arrive_radius:=0.2 -p timeout:=60.0
```

## 排错

| 现象 | 排查 |
| --- | --- |
| `Behavior Tree tick rate 100.00 was exceeded` | **无害**。CPU 争抢，导航照常成功。想消掉就把 `bt_loop_duration` 从 10 改到 20（50Hz） |
| 起 Nav2 时报 `filter_mask_server` 找不到 yaml | `~/.maps/current_map` 指的地图不存在或缺 `<name>.yaml`，见 [多地图与禁行区.md](多地图与禁行区.md) |
| 画的禁行区不生效 | `keepout_mask_reloader` 没起来？`ros2 node list \| grep reloader` |
| 规划不出路径 | 目标在禁行区/障碍里；或 global costmap 没收到 `/map` |
| 车贴着障碍走 | `keepout_filter` 排到 `inflation_layer` 后面去了 |
