# 里程计与雷达标定

三项实机标定的操作手册：**轮径（线速度）→ 轮距（角速度）→ 雷达 yaw**。
照着做即可，不需要额外背景知识。过程记录与推导见
`docs/spec/2026-08-11-实机几何改动同步.md`。

🤖 = 机器人会动。

---

## 什么时候要重标

| 换了什么 | 轮径 | 轮距 | 雷达 yaw |
| --- | :-: | :-: | :-: |
| 轮胎 / 轮子 | ✅ | ✅ | — |
| 底盘几何（轮距变了） | — | ✅ | — |
| 雷达或其安装座**拆下来重装** | — | — | ✅ |
| 整车重装但雷达连安装座整体移过去 | — | — | ❌ **不用** |
| 载重明显变化（影响轮胎压陷） | ✅ | — | — |
| 只换电机 / 编码器 | — | — | — |

> **判断一个标定值是否失效，问「它补的是哪个物理量」，不是「硬件动没动」。**
> 2026-08 底盘重做时按"硬件动了就作废"把三项全复位，结果轮径和雷达 yaw 的旧值
> 复标后都回到原值（差 0.05%）—— 轮径补的是轮胎压陷、雷达 yaw 补的是安装座机械角度，
> 两者都与底盘几何无关。真正失效的只有轮距。

---

## 顺序与依赖

```
轮径 ──必须先做──▶ 轮距          雷达 yaw（独立，随时可做）
```

**轮距的判据里含轮径比，轮径没标准就去标轮距，会把轮径误差吸进轮距。**

## A. 轮径标定（线速度）

**回填**：`config/hw_controllers.yaml` 的 `left/right_wheel_radius_multiplier`

### 步骤

1. 地面拉直线，起点终点做标记
2. 🤖 定速跑一段（下面是约 2 m；`--times` = 20 × 秒数）

   ```bash
   ros2 topic pub --rate 20 --times 60 /cmd_vel_keyboard geometry_msgs/msg/Twist \
     '{linear: {x: 0.3}, angular: {z: 0.0}}'
   ```

3. 卷尺量真实位移，读 `/diff_cont/odom` 的 X
4. **至少 8 组，距离跨度尽量大**（0.5 ~ 3 m）。少了看不出量尺偏差

### 算

对 `(真值, odom)` 做**两种**拟合，先看截距：

```
仿射   odom = a·true + b     ← b 必须 ≈ 0
纯尺度 odom = k·true         ← 用这个的 k
新 multiplier = 旧值 ÷ k     （左右两个同除，保持原比例）
```

**`|b| > 10 mm` 说明量尺基准错了，先修量法再算 k**，别当成"固定亏空"去查系统。
判别：真值 0 时 odom 必然是 0，若拟合直线外推不到原点，那条"固定亏空"就不是物理量。
（2026-08 踩过：真值多量了 0.167 m，把纯尺度误差伪装成了"尺度 + 固定缺口"两项。）

左右比例是跑直用的，**只能整体缩放，不能单独动某一个**。车固定往一侧偏时才调比例。

### 验（V7）

用**改后**的配置**另跑一趟**（标定集 ≠ 验证集）：

```
|odom − true| / true < 2%
```

## B. 轮距标定（角速度）

**回填**：`config/hw_controllers.yaml` 的 `wheel_separation_multiplier`

### ⚠️ 通道：必须读 `/diff_cont/odom`

`ekf_hw.yaml` 的 `odom0_config` 第 12 位（vyaw）是 `false`，**EKF 航向 100% 来自 IMU**。
改 `wheel_separation_multiplier` 对 `/odometry/filtered` 的 yaw **零影响** ——
读它做判据测到的是 IMU 标度误差，**会以"通过"的形式给出假阳性**。

> 那为什么还要标？`wheel_separation` 在 `diff_drive_controller` 里是双向的：
> 既算 odom 的 yaw（EKF 不用），也算 `cmd_vel` → 左右轮速的逆解（**在控制通路上**）。
> 错了会让 NeuPAN 的 MPC 增益失配、遥控转向手感不对。

### 步骤

1. 车头对准地面标记，**车静止**
2. **先对齐再起脚本**（累计从 0 开始，不用记初值）：

```bash
python3 - <<'EOF'
import math, rclpy
from rclpy.node import Node
from nav_msgs.msg import Odometry

def yaw_of(q):
    return math.atan2(2*(q.w*q.z+q.x*q.y), 1-2*(q.y*q.y+q.z*q.z))

class Accum(Node):
    def __init__(self):
        super().__init__('yaw_accum')
        self.s = {}
        for t in ('/diff_cont/odom', '/odometry/filtered'):
            self.s[t] = [None, 0.0]
            self.create_subscription(Odometry, t, lambda m, t=t: self.cb(t, m), 50)
        self.create_timer(0.5, self.report)
    def cb(self, t, m):
        y = yaw_of(m.pose.pose.orientation)
        prev, total = self.s[t]
        if prev is not None:
            d = y - prev
            d -= 2*math.pi*round(d/(2*math.pi))   # unwrap
            self.s[t][1] = total + d
        self.s[t][0] = y
    def report(self):
        a = self.s['/diff_cont/odom'][1]; b = self.s['/odometry/filtered'][1]
        print(f'轮式 {math.degrees(a):+9.2f}° ({a/(2*math.pi):+.4f}圈)   '
              f'EKF/IMU {math.degrees(b):+9.2f}° ({b/(2*math.pi):+.4f}圈)', flush=True)

rclpy.init(); rclpy.spin(Accum())
EOF
```

3. 🤖 **慢速**原地转（快了打滑会污染标定值）：

   ```bash
   ros2 topic pub --rate 20 /cmd_vel_keyboard geometry_msgs/msg/Twist \
     '{linear: {x: 0.0}, angular: {z: 0.5}}'
   ```

   `z=+0.5` 是逆时针，读数应为正。0.5 rad/s 下 10 圈约 125 s

4. **人工数满 10 圈** → Ctrl-C。车会滑过一点，用点动对回起始标记（每次约 1.7°）：

   ```bash
   ros2 topic pub --rate 20 --times 2 /cmd_vel_keyboard geometry_msgs/msg/Twist \
     '{linear: {x: 0.0}, angular: {z: 0.3}}'
   ```

5. 记两个累计值。**跑两次**取平均

### 算

```
k = 轮式累计yaw / IMU累计yaw          ← 真值用 IMU，不用名义 3600°
新 wheel_separation_multiplier = 旧值 × k
```

用 IMU 配对而不是 3600°，可消掉"是否正好转满 10 圈、点动对齐准不准"的误差；
IMU 自身 0.118% 的标度误差相对通常几个 % 的修正量可忽略。

### 验（V8）

用改后配置再转一次：

```
|轮式累计yaw − IMU累计yaw| / IMU累计yaw < 0.28%      （等价于 10°/3600°）
```

### 顺带记一笔（V8b）

同一次转圈里 `IMU累计yaw` 与名义 3600° 之差 = **IMU 标度误差**，是 IMU 改造前后的对照基线。
台架基线 4.27°/3600°（0.118%）。显著劣于此 → 换装碰坏了 IMU 轴向。

## C. 雷达 yaw 外参

**回填**：`launch/robot_bringup.launch.py` 的 `lidar_yaw:=`

### 精度地板在摆正，不在拟合

**量左右轮到墙的距离，调到相差 <1 mm。**
轮轴连线垂直于车体 x 轴，是车上最明确的物理基准。

```
基线 0.192 m，1 mm 差 → atan(0.001/0.192) = 0.30°  ← 这就是误差地板
```

用圆盘边缘（基线 0.22）理论上略好，但圆是曲面、对称点不好找准，实际更差。
思岚 C1 角分辨率本身约 0.72°，0.30° 已在传感器能力之内，**不必追求更高**。

### 步骤

1. 选墙：平直、无踢脚线突出、无杂物、不是玻璃或镜面，**至少 0.8 m 连续平直**
2. 车摆到墙前 **0.8~1.2 m**，按上面摆正
3. 蹲下沿车头方向看一眼前方 ±20° 扇区里有没有门框、纸箱、桌腿
4. 手离开车，确认完全静止，跑脚本（自动采 60 帧后退出）：

```bash
python3 - <<'EOF'
import math, numpy as np, rclpy
from rclpy.node import Node
from sensor_msgs.msg import LaserScan
import tf2_ros

FOV_DEG, RMIN, RMAX, NFRAME = 40.0, 0.25, 3.0, 60   # 前方 ±20°

class WallFit(Node):
    def __init__(self):
        super().__init__('wall_fit')
        self.buf = tf2_ros.Buffer(); tf2_ros.TransformListener(self.buf, self)
        self.acc = []
        self.create_subscription(LaserScan, '/scan_filtered', self.cb, 10)
    def cb(self, m):
        if len(self.acc) >= NFRAME: return
        try:
            t = self.buf.lookup_transform('base_footprint', m.header.frame_id, rclpy.time.Time())
        except Exception as e:
            self.get_logger().warn(f'等 TF: {e}', throttle_duration_sec=2.0); return
        q = t.transform.rotation
        yaw = math.atan2(2*(q.w*q.z+q.x*q.y), 1-2*(q.y*q.y+q.z*q.z))
        tx, ty = t.transform.translation.x, t.transform.translation.y

        pts = []
        for i, r in enumerate(m.ranges):
            if not (RMIN < r < RMAX): continue
            a = m.angle_min + i*m.angle_increment
            x, y = r*math.cos(a), r*math.sin(a)                       # laser 帧
            X = tx + x*math.cos(yaw) - y*math.sin(yaw)                # → base_footprint
            Y = ty + x*math.sin(yaw) + y*math.cos(yaw)
            if X > 0 and abs(math.degrees(math.atan2(Y, X))) < FOV_DEG/2: pts.append((X, Y))
        if len(pts) < 20: return

        P = np.array(pts)
        for _ in range(2):                                            # 拟合 + 剔离群 + 重拟合
            c = P.mean(0); U, S, Vt = np.linalg.svd(P - c)
            n = Vt[1]                                                 # 最小奇异向量 = 墙面法向
            d = np.abs((P - c) @ n)
            if len(P) < 20: break
            P = P[d < 3*d.std() + 1e-6]
        theta = math.degrees(math.atan2(n[1], n[0]))
        theta = (theta + 90) % 180 - 90                               # 折到 ±90°
        self.acc.append(theta)
        if len(self.acc) == NFRAME:
            a = np.array(self.acc)
            print(f'\n===== 墙面法向与车头 x 轴夹角 =====')
            print(f'  均值 {a.mean():+.3f}°   标准差 {a.std():.3f}°   n={len(a)}  用点数 {len(P)}')
            print(f'  当前 laser→base yaw = {math.degrees(yaw):+.4f}°')
            print(f'  修正: lidar_yaw −= {math.radians(a.mean()):+.6f} rad')
            rclpy.shutdown()

rclpy.init(); rclpy.spin(WallFit())
EOF
```

### 判读

| 输出 | 结论 |
| --- | --- |
| 标准差 **> 0.3°** | 数据不可信 —— 车动了 / 墙不平 / 有杂物。换位置重来 |
| **\|均值\| < 0.3°** | 已在摆正误差地板上，**不改**。再精调就是拟合噪声 |
| \|均值\| 更大 | 真实安装偏差，按 `lidar_yaw −= θ`（弧度）改，重启后**再测一次**确认 θ 趋近 0 |

修正式的符号已由实测确认（θ 随 `lidar_yaw` **同向**变化，增益 ≈1）。
不放心就改完重测，θ 变小即方向对。

---

## 三个反复踩到的坑

1. **通道错**：轮距标定读 `/odometry/filtered` 会假阳性（B 节开头）
2. **标定集自证**：用来算 multiplier 的数据不能再拿来验，必须另跑一趟
3. **拟合噪声**：残余量小于误差地板时不要继续精调
