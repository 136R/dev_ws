# my_bot 速查

## 编译

```bash
cd ~/dev_ws
colcon build --packages-select my_bot --symlink-install
source install/setup.bash

# 彻底重来（改了 xacro 结构、或构建产物错乱时）
rm -rf build/ install/ log/ && colcon build --symlink-install
```

## 启动仿真

```bash
ros2 launch my_bot launch_sim.launch.py                    # 默认 worlds/my_world_d.sdf

# 换世界
ros2 launch my_bot launch_sim.launch.py \
  world:=$HOME/dev_ws/src/my_bot/worlds/dynamic_indoor_crossing.sdf
```

现有世界（`worlds/`）：

| 文件 | 说明 |
| --- | --- |
| `my_world_d.sdf` | **默认**。4m×4m 围墙场地 + 5 个静态障碍 |
| `my_world.sdf` | 同上的早期版本 |
| `dynamic_indoor_crossing.sdf` | L 形室内通道 + 移动障碍（NeuPAN 动避验证） |
| `dynamic_indoor_crossing_static.sdf` | 同上但障碍静止 |
| `test_corridor.sdf` / `test_dynamic.sdf` | 早期测试场地 |
| `empty.world` | 空场 |

> Gazebo 是 **`-s` 无头启动**的，不会弹 GUI 窗口。想要 GUI 就去 `launch_sim.launch.py`
> 把 `gz_args` 里的 `-s` 去掉。

## 往世界里加东西

```bash
# ⚠️ -world 必须是 default（所有 sdf 里都是 <world name="default">，不是文件名！）
#    写错了会返回 "OK creation of entity" 但什么也不会生成
gz service -s /world/default/create \
  --reqtype gz.msgs.EntityFactory --reptype gz.msgs.Boolean --timeout 5000 -r \
  'sdf: "<?xml version=\"1.0\"?><sdf version=\"1.8\"><model name=\"box\"><static>true</static>
   <pose>0.6 -0.2 0.25 0 0 0</pose><link name=\"l\"><collision name=\"c\"><geometry><box>
   <size>0.3 0.3 0.5</size></box></geometry></collision><visual name=\"v\"><geometry><box>
   <size>0.3 0.3 0.5</size></box></geometry></visual></link></model></sdf>"'

# 查看世界里有什么
gz model --list
```

## 清场（重要）

反复起停时**务必确认上一轮死透了再起下一轮**。残留的 `parameter_bridge` / `laser_filter`
会和新一轮的重复往 `/clock` `/imu` 上发数据，**EKF 直接发散成 NaN 且不会自愈**。

```bash
pgrep -af "gz sim|slam_toolbox|nav2_|parameter_bridge|laser_filter|ekf_node|ros_gui_backend"
```

出现 `.nan` 就是这个原因：

```bash
ros2 topic echo /odometry/filtered --field pose.pose.position --once
```

## 排错

| 现象 | 排查 |
| --- | --- |
| `/odometry/filtered` 全是 `nan` | 有残留进程在重复发 `/clock` 或 `/imu`，杀干净重启 |
| spawn 的模型没出现 | `-world` 写成了文件名，必须是 `default` |
| 控制器没激活 | `ros2 control list_controllers`；等几秒再查 |
| SLAM 定位对不上 | 确认加载的世界和地图是同一个场地 |
