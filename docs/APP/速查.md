# APP 速查

## 启动

```bash
cd ~/ros_flutter_gui && sh ./start.sh          # 浏览器 http://127.0.0.1:8080
```

换过 `dist/` 之后浏览器要 **Ctrl+Shift+R** 硬刷新。

## 地图

```bash
# 存一张新图（必须 slam 处于 mapping 模式；名字不能叫 map）
~/dev_ws/src/my_bot_slam/scripts/save_map.sh <地图名>

# 切图：app 上点一下，或
curl -fsS "localhost:8080/setCurrentMap?name=<地图名>"
# 然后重启 slam + nav（它们不带 map:= 时会自动读 ~/.maps/current_map）

# 看列表 / 当前图 / 删图
curl -fsS localhost:8080/getAllMapList
curl -fsS localhost:8080/currentMap
curl -fsS "localhost:8080/deleteMap?map_name=<地图名>"
```

## 禁行区（画笔）

app 上画完点保存即可 —— `keepout_mask_reloader` 节点（随 `nav.launch.py` 启动）会在约 1s 内
自动热加载掩码，**不用重启任何节点**。

手动热加载（万一节点没起）：

```bash
ros2 service call /filter_mask_server/load_map nav2_msgs/srv/LoadMap \
  "{map_url: '$HOME/.maps/<地图名>/<地图名>.yaml'}"
```

> 路径是 `~/.maps/<名字>/<名字>.yaml` —— **目录名和文件名必须一致**。

检查生效：

```bash
ros2 topic echo /keepout_filter_mask --once --field info
ros2 topic echo /costmap_filter_info --once
# 禁行区在 /global_costmap/costmap 里应为 lethal；或发个目标看是否绕行
```

## 前端

```bash
# 重新构建 + 部署
export PATH="$HOME/flutter/bin:$PATH"
cd ~/ROS_Flutter_Gui_App/app && flutter build web --release
cd ~/ros_flutter_gui && rm -rf dist.bak && cp -a dist dist.bak \
  && rm -rf dist && cp -a ~/ROS_Flutter_Gui_App/app/build/web dist

# 回滚
cd ~/ros_flutter_gui && rm -rf dist && mv dist.bak dist

# 改完前端后重新导出补丁
cd ~/ROS_Flutter_Gui_App && git diff > ~/dev_ws/docs/APP/patches/0001-tile-refresh.patch
```

## 清场

仿真反复起停时，**务必确认上一轮进程死透了再起下一轮** —— 残留的 `parameter_bridge` / `laser_filter`
会和新一轮的重复往 `/clock` `/imu` 上发数据，EKF 直接发散成 NaN 且**不会自愈**。

```bash
pgrep -af "gz sim|slam_toolbox|nav2_|parameter_bridge|laser_filter|ekf_node|ros_gui_backend"
```
