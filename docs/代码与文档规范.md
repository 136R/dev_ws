# 代码与文档规范

写或改本仓库的自研代码、任何 `docs/` 下的文档之前读这份。
由 `.claude/skills/code-style/` 负责触发加载，不常驻上下文。

> `.claude/output-styles/`（回复风格）与 `.claude/skills/`（触发层）都已在 `.gitignore` 放行、
> 进版本库。换开发机 clone 后即生效，不用手动补。

## 一、注释规范

### 默认不写注释

代码能自己说清楚的事不要用注释重说一遍。只在下面四种情况写 —— 判据是
**「三个月后冷启动的 AI 读代码读不出来」**：

| 该写 | 因为 |
| --- | --- |
| **隐藏约束** | 这个值 / 这种写法为什么必须这样，谁规定的 |
| **微妙的不变量** | 跨文件耦合 —— 改这里必须同步改哪里 |
| **workaround** | 为什么不用显然的那种写法（针对某个具体 bug 或硬件怪癖） |
| **反直觉行为** | 违反了会出什么症状 |

不写的：复述代码在干什么、变更历史（git 有）、无主人无日期的 TODO。

```cpp
// ✗ 复述
// Start background RX thread
rx_running_ = true;

// ✓ 隐藏约束
// 这个 node 从不加进 executor —— 发布不需要 executor，且它只被 RX 线程碰。
// 加进 executor 会引入跨线程竞争。
```

### 语言：中文

新写的、以及本次改动碰到的注释一律中文。**存量英文注释不翻译** —— 模型读英文无障碍，
纯翻译没有收益。第三方代码（`sllidar_ros2`、`neupan_cpp`、固件的 Fusion 库、
CubeMX 生成的部分）一律不动。

### 硬规则：引用别处的值时只写指针

注释里出现另一个文件的具体数值，就是给未来埋一个会过时的副本。

```cpp
// ✗ 数值副本，源码一改这行就骗人
// 控制环 100Hz

// ✓ 指针
// 频率由 robot_config.h 的 CONTROL_FREQ_HZ 定；
// 改它必须同步 hw_controllers.yaml 的 update_rate 与 ekf_hw.yaml 的 frequency
```

**边界**：值就定义在注释下一行时，允许写推导过程 —— 那不是副本，是这个值的来源说明。

```cpp
// ✓ 保留：解释这个常量怎么算出来的
// Encoder counts per full wheel revolution (2000 CPR × 34 gear ratio)
static constexpr double COUNTS_PER_REV = 68000.0;
```

### 跨文件耦合要双向标注

只在一侧写「改我要同步 B」，改 B 的人看不到。两侧都标。

### 不要删 AI 自己写的注释

AI 写下的注释是它判断「下次编辑需要知道」的上下文，删掉等于剥夺它的记忆。
唯一该删的是明显复述型的冗余。

## 二、文档参数规范

### 文档不写具体数值

文档里的数值是源码值的副本，源码改了副本不会跟着改。AI 读到过时副本会沿错误前提推理，
代价是整轮返工 —— 远大于它多跑一次 `grep` 的成本。

写**约束关系 + 违反后的症状 + 指针**，数值让读者自己去源码取。

```markdown
✗ | sensor_timeout 必须 ≥ 2×(1/传感器频率) | ... | `ekf_hw.yaml` `sensor_timeout: 0.08` ≥ 2×10ms ✓ |
✓ | sensor_timeout 必须 ≥ 2×(1/传感器频率) | ... | `ekf_hw.yaml` 的 `sensor_timeout` |
```

关系不会过时，数值会。

### 指针格式：文件 + 键名，禁止行号

`` `ekf_hw.yaml` 的 `imu0` `` —— 不是 `ekf_hw.yaml:28`。

行号一漂，AI 就读到错误的行，**比没有指针更糟**：没指针它会去搜，有错指针它会直接信。
键名和符号名不会漂。

### 不变量表的列头

统一为：`不变量 | 违反后的症状 | 去哪看`

### 例外：这些地方保留数值

| 地方 | 为什么 |
| --- | --- |
| `docs/spec/*.md` | 确认卡是时点快照，记录的就是「当时是多少」 |
| 命令示例里的参数 | 删了命令就不可执行 |
| `docs/vendor/` | 厂商手册，不是我们维护的 |
| `docs/APP/` 的端口号 | 那是接口契约，不是可调参数 |
