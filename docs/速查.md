# 总速查（跨包）

给 AI 快速上手用的单页入口。各包的细节在各自的 `docs/`。

## 编译

```bash
cd ~/dev_ws
colcon build --symlink-install                                # 整个工作空间
colcon build --packages-select my_bot_nav --symlink-install   # 单个包
source install/setup.bash                                     # 每个新终端都要
```

**实机（arm64）编 neupan 必须带 PIC**，否则链接期报 `relocation R_AARCH64_*`：

```bash
colcon build --symlink-install --cmake-args -DCMAKE_POSITION_INDEPENDENT_CODE=ON
```

（WSL / x86_64 上实测不加也能编过，见 [neupan.md](../src/my_bot_nav/docs/neupan.md#编译实机-arm64-需要带-pic)。）

**新机器上必须先拉 submodule**，否则 `src/neupan_cpp` 是空的、NeuPAN 插件编译不出来：

```bash
git clone --recursive <repo>          # 或者 clone 完再补：
git submodule update --init --recursive
```

日志：`log/latest_build/<包名>/stdout_stderr.log`

## 仿真全链路

```bash
# 1. Gazebo（默认 my_world_d.sdf，无头）
ros2 launch my_bot launch_sim.launch.py

# 2. SLAM（地图取自 ~/.maps/current_map）
ros2 launch my_bot_slam slam.launch.py use_sim_time:=true mode:=localization

# 3. Nav2（已内含 keepout 禁行区）
ros2 launch my_bot_nav nav.launch.py use_sim_time:=true controller:=neupan

# 4. 上位机 GUI
cd ~/ros_flutter_gui && sh ./start.sh      # 浏览器 http://127.0.0.1:8080
```

## 实机全链路

```bash
ros2 launch my_bot_hw robot_bringup.launch.py     # 底盘（等 4 秒 EKF 才起）
ros2 launch my_bot_slam slam.launch.py mode:=localization
ros2 launch my_bot_nav  nav.launch.py  controller:=neupan
```

## 建图 → 存图 → 换图

```bash
# 建图
ros2 launch my_bot_slam slam.launch.py use_sim_time:=true mode:=mapping
ros2 run teleop_twist_keyboard teleop_twist_keyboard --ros-args -r cmd_vel:=/cmd_vel_keyboard

# 存图（必须在 mapping 模式；app 后端要在跑；名字不能叫 map）
~/dev_ws/src/my_bot_slam/scripts/save_map.sh <地图名>

# 换图：app 上点一下，或
curl -fsS "localhost:8080/setCurrentMap?name=<地图名>"
# 然后重启 slam + nav（不带 map:= 时自动跟随 current_map）
```

## 导航

ros2 action send_goal /navigate_to_pose nav2_msgs/action/NavigateToPose \
  "{pose: {header: {frame_id: 'map'}, pose: {position: {x: 1.0, y: 0.5}, orientation: {w: 1.0}}}}"

## 禁行区

在 app 上画完点保存即可 —— `keepout_mask_reloader` 约 1s 内自动热加载，**不用重启**。

## ⚠️ 全局不变量

违反了就出错，但从代码里看不出来。各包 `docs/README.md` 里有更细的。

| 不变量 | 违反后的症状 |
| --- | --- |
| **地图名不能叫 `map`** | 画的禁行区被 app 的实时镜像覆盖、悄悄消失 |
| **`serialize_map` 只在 mapping 模式可用，被拒时仍返回 `result=0`** | 存图静默失败 |
| **局部控制器只有 `rpp` 和 `neupan`** | 照着旧笔记调 MPPI/DWB —— 那些插件根本没加载 |
| **`nav.launch.py` 已内含 keepout** | 再单独起 `keepout.launch.py` → 节点重名 |
| **EKF 吃 `/imu_broad/imu`，不是 `/imu/data`** | 找不到 complementary filter —— 它是关着的 |
| **机器人几何有三份副本必须同步** | xacro / `hw_controllers.yaml` / `robot_config.h`（唯一真相源） |
| **Gazebo 世界名是 `default`，不是文件名** | spawn 返回 OK 但什么也不生成 |
| **仿真反复起停要杀干净残留进程** | EKF 发散成 NaN 且不自愈 |
| **新机器要拉 submodule** | `src/neupan_cpp` 空目录，NeuPAN 插件编译不出来 |
| **实机(arm64) 编译必须带 `-DCMAKE_POSITION_INDEPENDENT_CODE=ON`** | neupan 链接期报 `relocation R_AARCH64_*`，编不过（x86_64 上不加也能过）|
| **实机要给 `src/gz_ros2_control` 加 `COLCON_IGNORE`** | 板子没装 Gazebo，它找不到 `ignition-gazebo6` 而失败，**连带整个 build 中止** |
| **在板子上重新 clone 前要关掉 VS Code Remote** | 它会重建 `.vscode/c_cpp_properties.json`，导致 git checkout 被拒、工作树被回滚 —— clone 看似成功但 `src/` 是空的 |

```bash
# 起新一轮之前先确认干净
pgrep -af "gz sim|slam_toolbox|nav2_|parameter_bridge|laser_filter|ekf_node|ros_gui_backend"
```
